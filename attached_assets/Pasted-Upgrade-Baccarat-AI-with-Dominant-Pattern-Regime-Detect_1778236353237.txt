2. DOMINANT PATTERN REGIME
Use Core History only.

Detect:
- N1 = immediate repeat/switch momentum
- N2 = two-hand structure
- N3 = three-hand structure
- N4+ = four-hand or deeper structure

Initial Pattern:
- Do NOT use first 10 hands automatically.
- Detect first clear repeating structure from start of Core History.
- Continue until first valid break.
- Pattern before break becomes Initial Dominant Pattern.
- Lock only after at least 4 valid Banker/Player hands.

Valid transitions:
- N1 → N2
- N2 → N1
- N3 → N2
- N4+ → N3

Invalid direct jumps are ignored unless extremely confirmed.

Transition confirmation:
- candidate pattern appears 2 consecutive times
OR
- candidate pattern appears 3 times within last 5 valid Banker/Player hands
AND transition follows valid path.

Regime statuses:
- STABLE
- ANOMALY
- BROKEN
- TRANSITION WATCH
- PATTERN CONFIRMED

Rules:
- STABLE = normal logic
- ANOMALY = reduce confidence
- TRANSITION WATCH = force NO BET
- PATTERN CONFIRMED = allow bet only after consensus
- Tie does not count as anomaly, confirmation, or reset.

7. BET LEDGER / P&L TRACKER
Rename Backtesting to:
- Bet Ledger / P&L Tracker

Purpose:
- NOT an AI analyzer
- must NOT affect AI confidence
- must NOT affect AI prediction
- must NOT affect consensus
- only records money won/lost from actual AI bets

Editable settings:
- Flat Bet Amount
- default ₱600
- user can edit anytime
- Tie payout setting if Tie Mode is enabled

Recording logic:
If AI Analysis = NO BET:
- any result entered = SKIPPED
- no win/loss
- no bankroll change
- no ROI change
- no drawdown change
- no streak change

If AI Analysis = BET Banker:
- Banker result = WIN
- Player result = LOSS
- Tie result = PUSH

If AI Analysis = BET Player:
- Player result = WIN
- Banker result = LOSS
- Tie result = PUSH

If Tie Mode OFF:
- Tie is PUSH for Banker/Player bets

If Tie Mode ON and AI bet Tie:
- Tie result = WIN
- Banker/Player result = LOSS

P&L:
- Banker win = Flat Bet × 0.95
- Player win = Flat Bet × 1.00
- Tie push = ₱0
- Loss = -Flat Bet
- Tie win = Flat Bet × Tie payout setting

Ledger stats:
- flat bet amount
- total AI bets
- Banker bets
- Player bets
- Tie bets
- wins
- losses
- pushes
- skipped
- win rate = wins / (wins + losses)
- net P/L
- ROI %
- current bankroll change
- max drawdown
- current streak
- longest win streak
- longest losing streak
